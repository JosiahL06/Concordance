# Troubleshooting & FAQ

**Something is wrong? Start here.**

A round that is already in progress is saved as you go, so the first thing to
try with almost any problem is to close the app completely and open it again.

## The first thing to try

Most problems go away when you close the app completely and open it again. Your
round is saved as you go, so nothing is lost by doing this, and the round comes
back where you left it.

## Asking for help

If you need to report a problem, these details make it far easier to help:

- the device you are using and its version (for example, "Amazon Fire HD 10"),
- the version of the app, which you can see by tapping **About** on the home
  screen,
- what you tapped just before the problem happened,
- a screenshot, if you can take one.

You can report a bug or ask a question on the
[project's issues page](https://github.com/JosiahL06/Concordance/issues).
