# Amazon Fire HD 10 (recommended)

The Amazon Fire HD 10 is the tablet Concordance is built for. Fire tablets do
not use Google Play, so there is nothing to install first — you download one
file and open it. This page walks you through it.

## 1. Download the app

On the tablet, open the web browser and go to the project's
[Releases page](https://github.com/JosiahL06/Concordance/releases). Tap the file
called `app-release.apk` to download it. Fire tablets come with a browser called
Silk; if you prefer, you can copy the file onto the tablet from a computer and
put it in the Downloads folder instead.

## 2. Tell the tablet that this install is allowed

Android will not install an app until you say the source is trusted. On a Fire
tablet:

1. Open **Settings**.
2. Go to **Security & Privacy**.
3. Turn on **Apps from Unknown Sources**. On newer Fire tablets this setting is
   called **Install unknown apps**, and you switch it on for the app you are
   installing *from* — usually **Files** or **Silk**.

## 3. Install it

Open the **Files** app, open **Downloads**, and tap `app-release.apk`. If the
tablet shows a warning that this type of file could be harmful, tap **Install
anyway**. That warning appears for every app that did not come from an app
store; it is normal, not a sign that anything is wrong.

## 4. Open it, and find it again

When the install finishes, open the app. Its name is **Concordance**. New apps
on a Fire tablet do not always land on the home screen — if you cannot see it,
swipe up from the bottom of the home screen to open the **App Library**, and you
will find it there.

## 5. Get the tablet ready for a match

Two quick changes make the tablet easier to keep score on:

- **Keep the screen awake.** In **Settings → Display**, set the screen timeout to
  a long time, so the tablet does not go to sleep between questions.
- **Turn the tablet sideways.** Concordance is designed for use in landscape
  (wide) view. In **Settings → Display**, turn off **Auto-rotate screen** so the
  picture does not tip when you set the tablet down.

## 6. If the app will not install

- **"App not installed"** — usually means a different copy of Concordance is
  already on the tablet, or the download did not finish. Remove any older copy
  of the app, then download the file again and retry.
- **Not enough space** — check **Settings → Storage** and free up some room, then
  try again.
- **You cannot find the setting** in step 2 — the wording differs a little
  between Fire tablets. Look under **Security & Privacy** for **Apps from
  Unknown Sources**, or for **Install unknown apps**.
