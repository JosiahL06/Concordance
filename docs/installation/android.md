## Outline

1. **Download** `app-release.apk` from the Releases page.
2. **Allow installs from this source** — Android 8+ grants the permission
   *per app*: when the install prompt appears, tap **Settings** → allow your
   browser or file manager → back → **Install**. (Show both the prompt path and
   the manual path under Settings → Apps → Special access → Install unknown apps.)
3. **Play Protect warning** — "Unsafe app blocked" → *Install anyway*;
   explain it appears for any app not distributed through Play.
4. **Phone vs tablet** — landscape tablet is the supported shape; phone works
   for practice but the console is designed for ≥1280×800 dp.
5. **Minimum versions** — Android 7 (API 24) and up.
