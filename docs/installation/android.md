# Other Android devices

Any Android tablet or phone can run Concordance from the same file the Fire
tablet uses. If your device is an Amazon Fire tablet, use the
[Fire HD 10 page](fire-hd-10.md) instead — the steps are a little different.

## 1. Download the app

On the device, open your web browser and go to the project's
[Releases page](https://github.com/JosiahL06/Concordance/releases). Tap the file
called `app-release.apk` to download it.

## 2. Allow this source to install apps

Android will not install an app until you say the source is trusted. You do not
have to hunt for the setting: when you open the downloaded file, Android will
offer to install it and, if it is not already allowed, will send you to
**Settings**. Switch on **Allow from this source**, then go back and tap
**Install**.

If you would rather set it up ahead of time, open **Settings**, then
**Apps → Special access → Install unknown apps**, and allow your browser or
file manager there.

## 3. The Play Protect warning

You may see a warning such as **"Unsafe app blocked"**. Tap **Install anyway**
(or **More details**, then **Install anyway**). This warning appears for any app
that was not downloaded from the Play Store. It is not a sign that anything is
wrong.

## 4. Which devices work

Concordance is made for a tablet held sideways, the way a book lies open. A
phone will run it for practice, but the buttons and the scoreboard are laid out
for a screen the size of a tablet, so they will feel cramped on a phone. The app
needs Android 7 or newer.
