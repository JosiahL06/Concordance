# Which download do I need?

Every release includes a file for each kind of device. Find your device in the
table below, download the matching file, then follow its guide.

| Your device | Download | Guide |
| --- | --- | --- |
| Amazon Fire tablet (recommended) | `app-release.apk` | [Amazon Fire HD 10](fire-hd-10.md) |
| Any Android tablet or phone | `app-release.apk` | [Other Android devices](android.md) |
| Windows PC or touchscreen laptop | `concordance-windows-x64.zip` | [Windows](windows.md) |
| Linux desktop | `concordance-linux-x64.tar.gz` | [Linux](linux.md) |
| Mac | `concordance-macos.zip` | [macOS](macos.md) |

## Where to download

All of these files are on the project's
[Releases page](https://github.com/JosiahL06/Concordance/releases). Take the
newest release unless you have a reason to use an older one.

## The recommended device

An **Amazon Fire HD 10** tablet is what the app is built and tested around. It
is held on its side, the way a book lies open, and it runs Concordance without
any need for Google Play. Concordance was designed for tablets like this one, so
it is the safest choice if you are buying a device for the job.

## Before you start

There is nothing to sign up for. You do not need an account, and once the app is
installed it works without any internet connection. Installing takes about a
minute.

## What to expect along the way

- Every release includes a small text file called `SHA256SUMS`, which lists a
  short code for each download. It lets you check that the file you received is
  exactly the file the project built. See
  [Verifying your download](verifying-downloads.md).
- The Windows, Linux, and Mac versions are not yet signed, so your computer will
  show a warning the first time you open them. That warning is expected, and
  each guide explains exactly which button to press.
