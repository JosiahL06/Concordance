# Windows

Concordance comes to Windows as a folder of files rather than a setup program.
This page shows you how to get it running the first time.

## 1. Download it

On your PC, open the project's
[Releases page](https://github.com/JosiahL06/Concordance/releases) and download
the file called `concordance-windows-x64.zip`.

## 2. Unzip it

Right-click the downloaded file and choose **Extract All…**, then extract it
somewhere you will remember — your Desktop or your Documents folder is fine.

This step matters. The app has to run from the unzipped folder, because it needs
the other files that came with it. Opening `concordance.exe` from inside the zip
will not work.

## 3. Run it

Open the unzipped folder and double-click `concordance.exe`. The very first time
you open it, Windows takes a few seconds to get it ready; later launches are
faster. That delay is normal.

## 4. The first-launch warning

You will probably see a blue box titled **"Windows protected your PC"**. Windows
shows this for any app it does not recognise, and Concordance is not yet signed,
so the warning is expected:

1. Click **More info**.
2. Click **Run anyway**.

The app opens normally after that, and you will not be asked again on this PC.

## 5. Make it easy to find

Right-click `concordance.exe` and choose **Pin to Start**. Then the scorekeeper
can launch it from the Start menu instead of digging through Downloads.

## 6. Touch and display

Concordance opens in a wide window, ready for a touchscreen laptop. You do not
need a keyboard to keep score — every button is large enough to tap. There is no
installer yet; the app is a folder you keep and run, and a signed installer is
planned for a later release.
