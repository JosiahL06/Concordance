# Match summary

<!-- OUTLINE (docs pass): type = HOW-TO. Covers the end of a round and the
     export. Confirm the export details against the shipped code
     (`share_plus` sheet, PDF + CSV) before writing the file-format section. -->

**Goal:** close out the round and keep a record.

## To cover

- **Getting there** — finishing the last question, or opening Summary
  deliberately; "Done" pops back to Home.
- **What the summary shows** — final team totals, per-quizzer breakdown
  (correct/incorrect, fouls), quiz-outs/strike-outs, time-outs used, and the
  announcements the rulesets require.
- **Export as PDF** — what the page contains and that it is designed to be
  readable on paper; how the share sheet works on each platform.
- **Export as CSV** — the columns, one row per what, and who it is for
  (spreadsheets, record-keeping).
- **What is not exported** — nothing is uploaded anywhere; the file goes only
  where you send it from the share sheet.
- **Keeping a record without exporting** — the round stays on the device under
  Resume/History until deleted.
