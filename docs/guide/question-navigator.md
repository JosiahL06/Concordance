# Question navigator

**Goal:** read the round at a glance, and get back to any question.

## What it is

The navigator is the row of question numbers on the live screen. Each number
carries the marks for what happened on that question, so you can see the whole
round without hunting. It is the digital version of the marks you would make on
the paper scoresheet.

## Reading the marks

| Mark | What it means | On the paper sheet |
| --- | --- | --- |
| A value under the number (10, 20, 30) | The question's value, once you have set it | The point-value box |
| A score beside a quizzer | The question was answered — a **+** value for correct, a **−** half for incorrect | The written score |
| A circle around the number | The question was interrupted | The circled number |
| A slash across the number | The question was contested | The contest slash |
| An **F** by a quizzer's score | That quizzer fouled | The F mark |
| A struck-through number | The question was voided and read again | The struck-out cell |
| A plain number | Not yet read | An empty box |
| The highlighted number | The current question | The question in progress |

## Moving to a question

Tap a number to look at that question. On the Classic screen the grid behaves
the same way — tapping a cell moves you to that question. Remember that
**tapping a cell never scores it**. Scoring always happens in the console. That
catches people out at first, so it is worth saying twice.

## Correcting an older question

Because you can move to any question, you can go back and correct one. Move to
it, then score it as usual; the ruling is recorded against that question. See
[Undo & corrections](undo-and-corrections.md).

## Scrolling

A full match of twenty questions fits across the screen without scrolling on a
tablet held sideways. If a match goes to overtime, the extra questions are added
on the end, and the row scrolls to reach them.

## Announcing the round

Reading from the navigator is a quick way to tell the room where things stand —
which questions have been answered and how many are left. It shows the same
information the paper sheet's marks do.
