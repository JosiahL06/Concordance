**Goal:** read the round at a glance and get back to any question.

## To cover

- **What it is** — the strip/ledger of question numbers showing what happened
  on each one, on both the Modern and Classic live views.
- **Glyph table** — *mark ↔ meaning ↔ paper-scoresheet equivalent*:
  - answered correct / incorrect (value shown),
  - **circled** = interrupted,
  - **slash** = contested,
  - **`F`** = foul,
  - voided / substituted question,
  - not-yet-read question, current question.
- **Navigating** — tapping a mark to look at that question; on the Classic view
  the ledger cell *navigates* and never scores (state this explicitly, it is a
  common surprise).
- **Scoring an older question** — how this connects to Undo/corrections.
- **Scrolling behaviour** — 20 questions fit without scrolling on the target
  tablet; overtime questions append and scroll.
- **Reading to the room** — how the navigator helps announce a running state.
