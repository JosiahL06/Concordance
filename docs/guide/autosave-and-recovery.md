# Autosave & recovery

**The short answer:** if the tablet dies mid-match, the round is not lost.
Everything you have already recorded was written down as you went.

## Autosave

Every ruling is saved the instant you make it. There is no Save button and
nothing to remember. You can close the app, the tablet can run out of battery,
or it can be restarted — whatever was on the screen before the interruption is
still there afterwards.

## Resuming a round

Saved rounds appear on the home screen under **Resume round**. Tapping one opens
it exactly where you left off: the same score, the same question, and the same
undo history, so you can still step back through everything you recorded.

## What survives what

| What happens | What you keep |
| --- | --- |
| The app crashes or is forced closed | The round is safe |
| The tablet runs out of battery | The round is safe |
| The tablet is restarted | The round is safe |
| The app is updated | The round is safe |
| The app is uninstalled | The round is deleted — save a copy first |

If a round needs to outlive the app, save it as a PDF or a spreadsheet file
first. See [Match summary](match-summary.md).

## Deleting a round

You can delete a round from the **Resume round** list. The app asks you to
confirm first, because deleting cannot be undone.

## If something looks wrong

If a round will not open, or seems to be missing taps, do not uninstall the app
— that would remove the very thing you are trying to save. See
[Recovering a round](../troubleshooting/data-recovery.md).

## How it works

Rounds live in a small database file on the device itself — see
[Data & storage](../reference/data-and-storage.md). The app never sends anything
to a server, so bringing a round back never depends on anything except the
tablet in your hands.
