## Outline

| Screen | What it is for | Key regions |
| --- | --- | --- |
| **Home** | Start a new round, resume a saved one, open settings | Start / Resume list / Settings |
| **Setup** | Ruleset, teams, quizzers, seats, live-view choice | Ruleset tabs, roster fields, view picker |
| **Live scoring** | The actual scoring surface (two variants) | Scoreboard, question navigator, bottom console |
| **Summary** | Final scores, announcements, export | Totals, per-quizzer breakdown, export buttons |

- **Nav graph**: Home → Setup → Live (Modern *or* Classic) → Summary; back
  always returns toward Home, and every ruling has already been saved.
- **Modern vs Classic** in one paragraph: split-field vs scoresheet ledger,
  both driven by the same engine state (link to the explanation page).
- **The question navigator**: where it is on each view and what the marks mean
  (circled = interrupted, slash = contested, `F` = foul).
- **The bottom console** is the only place scoring happens — Classic ledger
  cells navigate, they never score.
