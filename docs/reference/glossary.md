# Glossary

**Goal:** define the terms the sport and the app use, all in one place.

## Quiz terms

| Term | What it means |
| --- | --- |
| **Quiz box** | The table where the quizzers sit and buzz in. The two sides of it are the Red team and the Green team. |
| **Quizzer** | A contestant on one of the two teams. |
| **Seat** | A quizzer's position at the table. The seats are numbered in order (Red 1, Red 2, Green 1, and so on). |
| **Bench** | A team's quizzers who are not sitting at the table. They can be swapped in during the match. |
| **Substitute** | A bench quizzer who swaps in for a seated quizzer. |
| **Question value** | How many points a question is worth: 10, 20, or 30. |
| **Correct answer** | An answer accepted by the officials. It earns the question's full value. |
| **Incorrect answer** | A rejected answer. It takes off half the question's value. |
| **Half-value deduction** | The rule that an incorrect answer costs half of what the question was worth — a 30-point question answered wrong is −15. |
| **Interruption** | A quizzer buzzing in before the question has finished being read. |
| **Contest** | A team's formal challenge to a ruling, in Teen Bible Quiz. |
| **Coach's Appeal** | The same idea in Junior Bible Quiz; two are allowed per team. |
| **Void** | A question thrown out and read again, keeping the same question number and value. |
| **Quiz out** | A quizzer reaching the ruleset's number of correct answers, which also earns a bonus. |
| **Strike out** | A quizzer reaching the ruleset's number of incorrect answers. |
| **Foul out** | A quizzer reaching the ruleset's number of fouls. |
| **Personal foul** | A foul charged to one quizzer. |
| **Team foul** | A foul charged to the whole team, such as a coach's foul. |
| **Time-out** | A short pause requested by a team. Each team has a limited number. |
| **Overtime question** | An extra question added when a match is tied after the last regulation question. |
| **Match** and **round** | One game between the two teams, from the first question to the last. |
| **Question number** | A question's place in the round, from 1 to 20 in regulation. |

## App terms

| Term | What it means |
| --- | --- |
| **Round** | One match's worth of scoring in the app. A round is what you start, resume, or delete. |
| **Ruling** | Anything you record — an answer, a foul, an interruption, a time-out. |
| **Console** | The strip of large buttons along the bottom of the live screen. All scoring happens here. |
| **Navigator** | The row of question numbers on the live screen. See [Question navigator](../guide/question-navigator.md). |
| **Mark** | A symbol on the navigator showing what happened on a question, such as a circle for an interruption. |
| **Modern view** | The live screen laid out as two team halves. |
| **Classic view** | The live screen laid out as a scoresheet grid. |
| **Notice** (or **alert**) | A message the app shows above the console, such as a quiz-out. See [Alerts](../guide/alerts.md). |
| **Undo** | The button that takes back the most recent ruling. See [Undo & corrections](../guide/undo-and-corrections.md). |
| **Autosave** | The app's habit of saving every ruling the moment you make it. |
| **Resume** | Opening a saved round and carrying on where you left off. |
| **Ruleset** | The set of numbers that describes one rulebook, such as Teen Bible Quiz 2025-26. See [Rulesets](../rulesets/index.md). |
| **Export** | Saving a finished round as a **PDF** (a printable score sheet) or a **spreadsheet** file. See [Match summary](../guide/match-summary.md). |
